## Organization Size Adaptations

### Small Organization (10-50 Applications)

| Aspect | Adaptation |
|--------|-----------|
| **Assessment Depth** | Light — focus on critical applications |
| **Timeline** | 12-16 weeks (compressed) |
| **Team Size** | 3-4 people |
| **Discovery** | 1-2 weeks, streamlined templates |
| **Analysis** | 1-2 weeks, focus on top 10-15 critical apps |
| **Evaluation** | 2-3 weeks, single hyperscaler deep-dive |
| **Planning** | 1-2 weeks, simplified roadmap |
| **Templates to Use** | Core templates only (skip detailed integration guides) |
| **Scoring** | Simplified scoring — 3 dimensions (Technical, Security, Business) |
| **Governance** | Lightweight — single steering meeting bi-weekly |
| **Reporting** | Executive Summary + Scorecard only |

### Mid-Market Organization (50-200 Applications)

| Aspect | Adaptation |
|--------|-----------|
| **Assessment Depth** | Standard — balanced coverage |
| **Timeline** | 16-20 weeks |
| **Team Size** | 5-6 people |
| **Discovery** | 2-3 weeks, full templates |
| **Analysis** | 2-3 weeks, all 5 dimensions |
| **Evaluation** | 3-4 weeks, 2-3 hyperscaler comparison |
| **Planning** | 2-3 weeks, detailed roadmap |
| **Templates to Use** | All core + selected integration guides |
| **Scoring** | Full 5-dimension scoring model |
| **Governance** | Standard — steering committee weekly |
| **Reporting** | Full report suite |

### Enterprise Organization (200+ Applications)

| Aspect | Adaptation |
|--------|-----------|
| **Assessment Depth** | Comprehensive — detailed analysis |
| **Timeline** | 20-24 weeks |
| **Team Size** | 8-10 people |
| **Discovery** | 3-4 weeks, full templates + CMDB integration |
| **Analysis** | 3-4 weeks, all dimensions + deep-dives |
| **Evaluation** | 4-5 weeks, full multi-cloud comparison |
| **Planning** | 3-4 weeks, detailed multi-wave roadmap |
| **Templates to Use** | All templates + integration guides + customization |
| **Scoring** | Full 5-dimension with industry customization |
| **Governance** | Full governance model with working groups |
| **Reporting** | Full report suite + data exports |
| **Additional** | Parallel team execution, data aggregation procedures |

## Technology Landscape Adaptations

### Legacy-Dominant Environment

**Characteristics**: Mainframe, COBOL, on-premises only, limited automation

| Adaptation | Details |
|-----------|---------|
| Technical scoring emphasis | Increase weight to 35% (architecture modernization is key) |
| Additional criteria | Mainframe offloading assessment, COBOL migration options |
| Migration approaches | Emphasize Rehost and Replatform over Refactor |
| Timeline adjustment | Add 25-50% to standard timeline |
| Skills assessment | Include cloud skills gap analysis |
| Risk emphasis | Higher weight on operational risk (unfamiliar cloud ops) |

### Modern Environment

**Characteristics**: Containers, microservices, CI/CD, some cloud-native

| Adaptation | Details |
|-----------|---------|
| Technical scoring emphasis | Reduce weight to 20% (already cloud-compatible) |
| Additional criteria | Multi-cloud strategy, FinOps maturity |
| Migration approaches | Emphasize Replatform and Refactor |
| Timeline adjustment | Reduce by 20-30% from standard |
| Focus areas | Cost optimization, governance, compliance |

### Hybrid Environment

**Characteristics**: Mix of legacy and modern, some cloud adoption

| Adaptation | Details |
|-----------|---------|
| Segmentation | Assess legacy and modern workloads separately |
| Scoring | Use different weight profiles per segment |
| Migration approach | Tiered — modern apps first, legacy apps later |
| Additional criteria | Hybrid connectivity, data synchronization |
| Governance | Separate working groups for legacy vs. modern |
