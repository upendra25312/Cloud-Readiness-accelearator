# Cloud Readiness Accelerator

> A cloud-agnostic framework authored by expert teams across Microsoft Azure, AWS, and Google Cloud — empowering organizations to assess, plan, and execute cloud adoption with confidence.

---

## Overview

The **Cloud Readiness Accelerator** is a practitioner-grade toolkit designed by:

- **Microsoft Expert Azure Cloud Architects**
- **Senior Project Managers & Program Leads**
- **AI Architects** (Microsoft, Google, AWS)
- **Pre-Sales Architects** (Microsoft, AWS, Google Cloud)
- **Alliance Partners** (Microsoft, AWS, Google Cloud)
- **Senior Directors, Cloud Solutions Architecture** (Microsoft, AWS, Google Cloud)

It provides a structured, repeatable approach to cloud readiness — from initial assessment through migration, governance, security, and ongoing optimization — across **Azure**, **AWS**, and **Google Cloud Platform (GCP)**.

## Quick Start

1. **Assess** — For Azure migrations, start with the [Microsoft SMART Assessment](assessments/smart-migration-assessment.md) to get a 10-category Azure migration readiness score. For multi-cloud, use [`assessments/cloud-readiness-assessment.md`](assessments/cloud-readiness-assessment.md).
2. **Plan** — Use the relevant cloud framework in `frameworks/` to architect your target state.
3. **Secure** — Apply the Zero Trust and compliance controls in `security/`.
4. **Govern** — Establish landing zones and policies with `governance/`.
5. **Optimize** — Continuously optimize costs and performance using `cost-optimization/`.
6. **Innovate** — Leverage AI/ML cloud platforms with `ai-ml-readiness/`.
